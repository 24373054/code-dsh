# 你的 AI 代理，有了一个可信的工作台

每天，你的代理都在替你处理付款、对账和结算。信任平台让你像管理一支团队一样管理它们：
为每个代理设定额度与边界，代理在边界内自动执行；只有超出边界的事情，才交到你手上。

## 为什么需要它

会替你花钱的 AI 代理，和普通聊天机器人完全不是一回事。它可能理解错一张发票，可能被一封伪造邮件骗走款项，
也可能在你不注意的时候，把额度用到了不该用的地方。

传统的做法是给代理一个 API Key 和一张公司卡——这等于让它无限制地替你做决定。
信任平台换了一种方式：**把「代理能做什么」写清楚，并让每一次动作都留下痕迹**。

- 每个代理都有明确的职责和付款额度；
- 超出额度、陌生收款账户、异常金额的情况，会自动停下来等你确认；
- 每一笔付款从授权到结算，都有可核对的记录。

## 工作台里有什么

信任平台以 DSH 插件的形式工作。在对话页签点一下工作台按钮，工作台就会停靠在对话右侧，
你一边和代理对话，一边处理审批，不用切换窗口。

| 页面 | 你会在这里做什么 |
| --- | --- |
| 总览 | 今天需要你关注的事情、本月交易额、委托链健康度、近 7 天趋势与风险分布 |
| 审批 | 处理被规则挑出来的人工复核；通过后任务继续，拒绝则终止并留下记录 |
| 付款任务 | 查看每一笔付款的进度、风险决策、执行代理和完整链路 |
| 代理 | 认识你的代理团队：职责、信任分、额度、成功率与最近活动 |
| 委托授权 | 给代理分配权限：单笔上限、每日上限、有效期与可执行动作 |
| 治理策略 | 设定拦截、转人工、限流的风险阈值，并发布新的策略版本 |
| 审计 | 查看异常案件、证据覆盖率，生成给审计与财务的归档报告 |
| 设置 | 工作区信息、提醒偏好、数据导出与恢复 |

## 一个典型的工作日

1. **早上打开总览。** 三件需要你关注的事情已经排好优先级：一笔复核超时、一笔付款被拦截、一个案件被升级。
2. **处理例外。** 打开审批，看一眼风险分和关联代理；确认收款账户无误后点「通过复核」，任务自动继续。
3. **检查边界。** 在委托授权里确认每个代理的单笔与每日额度；快到期的额度会提前提醒你。
4. **交付审计。** 在审计里结束案件，导出本次调查的报告，交给财务或合规团队归档。

## 安全边界

- **逐级收紧的授权。** 委托授权像公司的审批权限一样层层下放，每一级只能收紧、不能放宽；
  上级撤销或到期后，下游代理立刻失去权限。
- **只处理例外。** 低风险付款自动放行，中风险限流，高风险转人工，明确异常直接拦截。
  你只需要处理被规则挑出来的事情。
- **全程留痕。** 每一次授权、审批、结算都会写入不可绕过的审计记录，时间、代理、金额与依据一应俱全。
- **资金安全。** 信任平台不发起转账，也不经手资金，更不保存支付渠道的密钥；它负责判断
  「该不该付、谁批准、证据是否齐全」，真正的付款由你接入的支付渠道执行。
- **数据留在本机。** 工作区数据保存在这台电脑上，不上传、不外发。

## 数据与隐私

- **本地优先**：工作区数据保存在本机；产品不连接任何云端服务。
- **零外传**：产品不会上传工作区数据，也不会把付款信息发送给第三方。
- **可导出**：随时下载完整快照，用于评审、存档或迁移前的备份。
- **可恢复**：一键恢复到示例初始状态；体验期间产生的记录会被清除。

## 常见问题

**数据存在哪里？**
保存在本机的插件数据目录中。可以在「设置 → 数据与备份」查看位置并导出完整快照。

**能接真实付款吗？**
本产品不发起转账、不经手资金，也不保存支付渠道的密钥。它负责判断一笔付款「该不该付、谁批准、
证据是否齐全」，并留下可核对的记录；真正的资金动作由你接入的支付渠道执行。

**会不会上传我的数据？**
不会。产品没有遥测，也不连接云端服务；所有请求都在本机完成。

**可以几个人一起用吗？**
当前工作区面向单机本地部署：数据保存在本机，工作台随 DSH 一起启动。
